# منصة جليس — مكتبة علي المتروك (Jalees Platform)

## نبذة كاملة عن المشروع (Project Overview)
"جليس" هو تطبيق ويب تقدمي (PWA) تم تصميمه خصيصاً للمهندس علي المتروك ليكون الرفيق الذكي للقراءة الورقية. يهدف التطبيق إلى دمج متعة القراءة من الكتاب الورقي الملموس مع قوة الذكاء الاصطناعي التوليدي، بحيث يوفر تجربة محادثة صوتية سلسة، وتوثيقاً منظماً للأفكار، وقاعدة بيانات سحابية مركزية لا تضيع.

تم بناء التطبيق في ملف `index.html` واحد (Single Page Application) ليسهل تعديله وتطويره باستخدام محررات الأكواد الذكية مثل "ساني" (Cursor / Windsurf).

### 🛠 التقنيات المستخدمة (Tech Stack):
1. **الواجهة الأمامية (Frontend):** HTML5, Tailwind CSS (عبر الـ CDN للتصميم السريع والمتجاوب).
2. **قاعدة البيانات والسحابة (Backend):** Google Firebase (Firestore Database + Anonymous Authentication).
3. **الذكاء الاصطناعي (AI):** 
   - **Claude API عبر SDK الرسمي @anthropic-ai/sdk (نموذج قابل للاختيار؛ الافتراضي claude-opus-5-5):** المحرك الرئيسي للنقاش، استخراج بيانات أغلفة الكتب بصرياً، وتوليد الملخصات.
4. **القدرات الصوتية (Voice Engine):**
   - **الاستماع:** Web Speech API (لتحويل كلام المستخدم إلى نص مباشرة).
   - **النطق:** دعم مدمج لـ ElevenLabs API (لصوت بشري واقعي) + بديل مجاني عبر متصفح الجهاز.
5. **معالجة الملفات محلياً:** مكتبة `PDF.js` لاستخراج النصوص من ملفات الـ PDF المرفقة محلياً داخل المتصفح بدون الحاجة لخادم (Server-less).

---

### ✨ المميزات المعمارية والبرمجية (دليل المطور للتعديل):

1. **نظام التبويبات الثلاثة (Tabs Routing):**
   - التطبيق مقسم إلى 3 أقسام (الرئيسية `tab-home`، النقاش `tab-discuss`، الأرشيف `tab-archive`). يمكنك التعديل على أي قسم بإضافة فئات (Classes) من Tailwind.

2. **التخزين المزدوج (Dual-Sync Architecture):**
   - يستخدم التطبيق كائن `state` يحفظ بيانات المكتبة.
   - **الحفظ التلقائي:** يتم حفظ الحالة في `localStorage` فوراً لضمان السرعة، ثم تُرفع خلفياً إلى `Firebase Firestore` في مستند باسم `ali_almatrouk_profile`.

3. **معايرة الصفحات (Dynamic Page Offset):**
   - لأن الطبعات الورقية تختلف عن الإلكترونية، توجد ميزة `pageOffset`. إذا أدخل المستخدم أن الصفحة 100 ورقياً تساوي 85 إلكترونياً، فإن `pageOffset` سيكون `15-`، وعندما يناقش الذكاء الاصطناعي سيقوم بجمع (`paperPage + pageOffset`) لقراءة النص الصحيح من الـ PDF.

4. **محركات البحث المزدوجة (Dual Search APIs):**
   - عند إضافة كتاب، يبحث التطبيق أولاً في `Google Books API`. إذا كانت النتيجة فارغة، ينتقل تلقائياً للبحث في `OpenLibrary API` لضمان شمولية البحث عن الكتب العربية.

5. **الرؤية الحاسوبية السحابية (Multimodal Vision):**
   - دالة `handleCoverPhoto` تقوم بتصغير الصورة محلياً (Canvas Resize) قبل إرسالها إلى `Claude API` كـ `base64`. يقوم Claude باستخراج بيانات الغلاف الأمامي (JSON) أو تلخيص الغلاف الخلفي تلقائياً.

---

### 🔧 كيف تقوم بتعديله في برنامجك (Cursor / ساني)؟
1. افتح ملف `index.html` في المحرر الخاص بك.
2. الكود البرمجي (JavaScript) موجود بالكامل في الأسفل داخل وسم `<script type="module">`.
3. واجهة المستخدم (HTML) تستخدم `Tailwind CSS`، يمكنك تعديل الألوان (مثلاً استبدال `amber-400` بـ `blue-400`) مباشرة من الكلاسات.
4. إعدادات الـ Firebase موجودة في بداية سكريبت الـ JS، وهي مرتبطة بمشروعك الحالي `jalees-a0670`.

تم بناء هذا الكود ليكون "نظيفاً وخالياً من الاعتمادات المعقدة" (No Build Tools needed)، فقط احفظ الملف وارفعه ليتم التحديث.

## 🛠 تحديث الإصلاحات (النسخة 5)
- إصلاح `syncToCloud` غير المعرّفة على `window` (كانت تُسقط حفظ الكتاب وتغيير الصفحة والحذف).
- إعادة كتابة البحث: Google Books + OpenLibrary معًا، اختيار بالفهرس، وملء الحقول والغلاف.
- نصوص الـ PDF صارت في IndexedDB على الجهاز (لا تُرفع للسحابة، حدّ Firestore ≈ 1MB).
- إضافة `nextQuote`، وزر تحديث الملخص، وحذف مناقشة، وإصلاح هروب HTML (XSS).
- مفتاح Claude يُرسل في الترويسة، مع نموذج قابل للتعديل (الافتراضي gemini-2.5-flash) وبدائل تلقائية.
- Tailwind مبني مسبقًا في `styles.css` (بدون CDN)، وأُضيفت ملفات PWA: `manifest.json` و`sw.js` والأيقونات.

## 🚀 النشر
ارفع كل الملفات (index.html, styles.css, manifest.json, sw.js, icon*) إلى GitHub Pages أو Firebase Hosting. لإعادة بناء CSS بعد تعديل الكلاسات:
`npx tailwindcss@3.4.17 -c tailwind.config.js -i in.css -o styles.css --minify`

## 🔄 النسخة 6: الاعتماد الكامل على Claude
- كل الذكاء الاصطناعي (النقاش، قراءة الأغلفة، التلخيص) يمرّ عبر Claude؛ لا يوجد أي اعتماد على Gemini.
- المفتاح يوضع في ⚙️ (من console.anthropic.com) ويُحفظ على الجهاز فقط. الاستدعاء من المتصفح مباشرة بعلم `dangerouslyAllowBrowser`، فلا تشارك الرابط مع من لا تثق به لأن مفتاحك مخزّن في متصفحك أنت فقط.
- اختيار النموذج من شاشة النقاش أو الإعدادات، وزر «حدّث القائمة» يجلب نماذج حسابك.
- إدارة الملفات: إضافة/استبدال/إزالة ملف PDF أو نص لأي كتاب من الرئيسية.
- الصوت: تقسيم الردود لجمل مع وقفات، اختيار أفضل صوت عربي متاح تلقائيًا، قائمة أصوات وسرعة قابلة للتعديل، ومفتاح ElevenLabs اختياري. والردود تُكتب أصلًا بأسلوب مسموع (جمل قصيرة بلا رموز).

## 📚 النسخة 7: المكتبة والنقاش الذكي
- **مكتبتي:** تبويب لكل الكتب (فتح، تعديل، حذف، بحث)، وتبديل سريع بين الكتب، وأرشيف للكتاب الحالي أو لكل الكتب مع تعديل المناقشات وحذفها وتصديرها Markdown.
- **نسخة رقمية تلقائية:** بالبحث باسم الكتاب (أو من قراءة الغلاف) يبحث التطبيق في أرشيف الإنترنت (Internet Archive) عن نسخ حرة ويحمّلها: نص OCR أو EPUB أو docx أو PDF. الكتب المحمية بحقوق النشر غالبًا لا توجد، فيرفع المستخدم نسخته (PDF/EPUB/docx/txt).
- **أسئلة ذكية:** أفضل الأفكار، أفضل الاقتباسات (تُضاف لاقتباس اليوم)، تلخيص، نقد، اختبرني، كتب مشابهة، شرح الصفحة، ربط بنقاشاتك. تُحفظ في الأرشيف.
- **الرد صوتي أو كتابي:** زر تبديل في شاشة النقاش. والمحادثة تظهر كسلسلة رسائل.
- الأسئلة العادية تستعين بالصفحات المجاورة ومقاطع مرتبطة بالسؤال من نص الكتاب.

## 🔐 النسخة 8: تخزين مؤقت وتكلفة وتسجيل دخول Google
- أسئلة «الكتاب كله» تضع نص الكتاب أولًا في كتلة system مع `cache_control`، فتُحسب إعادته بسعر أقل في الأسئلة التالية خلال دقائق. وتظهر تكلفة كل رد التقريبية ونسبة الكاش، وإنفاق الشهر في ⚙️.
- المزامنة السحابية صارت بحساب Google (بدل الدخول المجهول). بدون تسجيل دخول تبقى المكتبة على الجهاز.
- القواعد: `firestore.rules` (مستوى 1) و`firestore.rules.owner-only` (مستوى 2، بريدك فقط).
